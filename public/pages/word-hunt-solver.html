Word Hunt Solver

Built a full-stack solver for GamePigeon Word Hunt (Flask, PostgreSQL, Docker) that finds every valid word on a board, ranks the best-scoring paths, and saves each user's performance history behind OAuth login, deployed live on Fly.io with managed AWS RDS.

Full production deploy: a Flask + PostgreSQL backend, Dockerized and running live on Fly.io with managed AWS RDS, built solo end to end.

Implementation Notes

Designed backend endpoints for board analysis, scoring, and history retrieval with fast response for repeated lookups.

Implemented a Trie-powered solver to efficiently enumerate valid words and maximize score output per board.

Persisted board results in PostgreSQL to compute percentiles and historical ranking trends.

Containerized the app with Docker and deployed with Fly.io + managed AWS RDS infrastructure.

Added OAuth login so a user's scores and board history save to their own account instead of resetting every session.
